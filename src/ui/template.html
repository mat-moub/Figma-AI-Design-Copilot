Welcome to UX Writer Copilot

Generate wording alternatives for any text node in Figma using AI. Let's get you set up in 3 quick steps.

  • ✍️ Select any text node and get AI-powered wording suggestions
  • 💬 Ask UX writing questions in Ask mode — no edits needed
  • 🎯 Context-aware: AI reads your Figma layout for better copy
  • 🔁 Generate multiple alternatives at once and apply with one click
  • 🤖 Supports Gemini, OpenAI, Anthropic, and Mistral

You're all set!

Start improving your copy by selecting a text node in Figma and typing a prompt. Here are some tips to get the most out of the plugin.

  • Generate mode Select a text node, describe the wording you want, and get alternatives
  • Ask mode Ask UX writing questions and get AI advice without modifying anything
  • Alternatives Set a number to generate multiple copy options at once
  • Apply Click "Apply" on any alternative to write it directly into the selected text node
  • Auto-selection Select any text node in Figma and the plugin detects it automatically
  • New conversation Use the refresh icon in the chat header to start fresh
  • Settings Change provider, model, or functional contexts anytime
